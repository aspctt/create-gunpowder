	+ Split the documentation: README for GitHub, DESCRIPTION for the mod pages

* 2026-01-06: 1.0.1

	+ Raise the Gradle heap to 4G
	+ No gameplay changes

* 2026-01-06: 1.0.0
	+ Initial release for Minecraft 1.21.1 on NeoForge, requiring Create 6.0.9
	+ Add Flint Shard, Carbon Dust, Volatile Powder, and Mineral Dust, in a Create: Gunpowder creative tab
	+ Pressing: Flint --> Flint Shard
	+ Milling: Coal or Charcoal --> 2x Carbon Dust
	+ Milling: Sand or Sandstone --> 2x Mineral Dust
	+ Mixing: Flint Shard + Carbon Dust --> Volatile Powder
	+ Heated mixing: Volatile Powder + Mineral Dust + 250mB Water --> 2x Gunpowder
